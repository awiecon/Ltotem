# LTotem — Paper 1.21.11

Плагин с пятью кастомными тотемами:

- **Тотем стойкости** — оранжевое название, +2 сердца (+4 HP) и Resistance I, пока находится в основной или левой руке.
- **Тотем скорости** — голубое название, Speed I, пока находится в основной или левой руке.
- **Судный тотем** — фиолетовое название, после срабатывания даёт Resistance IV на 20 секунд.
- **Тотем исцеления** — красное название, после срабатывания восстанавливает здоровье до максимума.
- **Тотем тьмы** — чёрное название, после срабатывания даёт Darkness на 20 секунд игрокам в радиусе 15 блоков, кроме владельца.

Команда `/ltotem` доступна **только OP** и открывает меню выдачи тотемов.

## Сборка

Требуется JDK 21. Paper для 1.20–1.21.11 использует Java 21. В проекте используется Paper API `1.21.11-R0.1-SNAPSHOT`.

Если установлен Maven:

```bash
mvn package
```

Готовый JAR будет в `target/LTotem-1.0.0.jar`.

## Установка

1. Соберите проект.
2. Положите `LTotem-1.0.0.jar` в `plugins/`.
3. Запустите сервер.
4. Настройте `plugins/LTotem/config.yml`.
5. Перезапустите сервер.

## Конфиг

В `config.yml` можно менять:

- названия и цвета;
- материал тотема;
- усиление и длительность эффектов;
- бонус максимального здоровья;
- радиус Тотема тьмы;
- слоты и размер GUI;
- включение/выключение каждого тотема.

Для эффектов, действующих пока тотем в руке, `duration-seconds: -1` означает постоянное обновление эффекта, пока тотем находится в руке.
