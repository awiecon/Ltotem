# Как получить готовый JAR без установки Java/Maven

1. Создай новый репозиторий на GitHub (можно Private).
2. Загрузи в него **содержимое этой папки**, включая `pom.xml`, `src/` и `.github/`.
3. Открой вкладку **Actions**.
4. Выбери workflow **Build LTotem**.
5. Нажми **Run workflow** (или дождись автоматической сборки после загрузки файлов).
6. Открой завершённый запуск workflow.
7. Внизу страницы найди **Artifacts** → `LTotem-jar` и скачай архив.
8. Внутри архива будет настоящий `LTotem-1.0.0.jar`.
9. Положи этот `.jar` в папку `plugins` Paper 1.21.11 и перезапусти сервер.

Важно: ZIP проекта нельзя просто переименовать в `.jar`. JAR должен быть собран Maven.
